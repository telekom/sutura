# Skill library

Specialist material, **not** discoverable. Nothing routes here automatically: open one of
these only when an active skill in `.agents/skills/` points at it, or when a human asks for
it by name. That is the whole difference between the tiers - see
`.agents/skills/agent-system/skill-policy/SKILL.md`.

All of these are mirrors of `github.com/addyosmani/agent-skills` (MIT) at commit `5a5ea45e806f`,
2026-08-21. Each states its own provenance. Where one conflicts with `AGENTS.md` or an active
skill, those win.
