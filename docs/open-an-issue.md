# Open an issue

Open every bug report and every proposal on the
[issue tracker](https://github.com/telekom/sutura/issues). Choose one of the two templates:

| Template        | Use it when                                                                |
| --------------- | -------------------------------------------------------------------------- |
| Bug report      | sutura behaves differently from what it should                             |
| Change proposal | You want a capability, a change to the tool surface, or a change to a rule |

For a bug report, paste the actual error and the narrowest command that shows it. If the error
only occurs in CI, link the run.

The repository is public and everything in it is world-readable. Write no internal names, host
names, tokens or personal data in an issue.

Do not open a public issue for a suspected vulnerability.
[Report a security issue](report-a-security-issue.md) instead.
