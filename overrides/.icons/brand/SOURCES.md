# Brand icons

Each file here is the product's own logo, copied from the source below. The SHA-256 is of the source: `bitol.svg` differs from it by the final newline that the repository's text hygiene adds, and no file differs otherwise. Material inlines each SVG into the page as `:brand-<name>:`. `cargo xtask check-docs` refuses an icon with an element outside plain SVG drawing, an event attribute or a reference that leaves the document.
