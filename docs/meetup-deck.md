# Meetup slides

The slides of a talk that introduces sutura: the problem, the four properties, the architecture, and
two examples to run. <a href="../slides/">Open the slides</a>.

The deck is in
[`slides/2026-introducing-sutura`](https://github.com/telekom/sutura/tree/main/slides/2026-introducing-sutura).
`nix build .#slides` builds it. To edit it, run `npm ci` and then `npm run dev` in that directory.
A local `just docs` does not include the deck.
