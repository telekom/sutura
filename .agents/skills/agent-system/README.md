# Agent system

How skills themselves are discovered, imported and maintained.

| Skill | Entry point | When to open |
| --- | --- | --- |
| `using-skills` | `using-skills/SKILL.md` | Start of a session, or when the router's intent list does not obviously match. Also carries the behaviours that hold whichever skill is loaded. |
| `skill-policy` | `skill-policy/SKILL.md` | Importing, updating or removing a skill; deciding active tier versus library. |
